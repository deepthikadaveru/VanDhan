# VanDhan ScholarConnect

### Unified Scholarship Platform for Tribal Students

VanDhan ScholarConnect is a unified digital scholarship platform designed to simplify scholarship discovery, eligibility checking, application, verification, and payment tracking for tribal students.

The platform brings the complete scholarship journey into a single, student-centric experience.

> **One verified profile. One scholarship timeline. One trusted journey.**

---

## 🌐 Live Demo

**[VanDhan ScholarConnect](https://van-dhan-scholar-connect.vercel.app/)**

---

## 🎯 Problem Statement

Students applying for scholarships often face fragmented information, complicated eligibility requirements, repeated document submission, and limited visibility into application and payment status.

These challenges can lead to:

- Difficulty discovering relevant scholarships
- Unclear eligibility requirements
- Repeated submission of the same documents
- Limited application-status visibility
- Difficulty tracking scholarship disbursement
- Language and accessibility barriers
- Lack of transparency during verification

VanDhan ScholarConnect addresses these challenges through a unified scholarship lifecycle.

---

## 💡 Solution

VanDhan ScholarConnect provides a single platform where students can:

1. Create and verify their profile
2. Discover relevant scholarship schemes
3. Check scholarship eligibility
4. Submit applications
5. Manage and reuse documents
6. Track application verification
7. Monitor scholarship payment status
8. Access multilingual assistance through **JAGO**

The platform also provides an officer-facing workflow for application review and processing.

---

## ✨ Key Features

### 🎓 Unified Scholarship Dashboard

A centralized dashboard that allows students to view:

- Available scholarships
- Eligibility status
- Submitted applications
- Verification progress
- Scholarship status
- Payment information

---

### 🧠 Smart Eligibility Check

Students provide relevant academic and personal information to determine which scholarship schemes may match their eligibility.

This reduces the need to manually navigate multiple scholarship requirements.

---

### 📄 Digital Document Wallet

The platform provides a reusable document-management workflow designed around digital document access.

Instead of repeatedly submitting the same documents for different applications, verified documents can be reused throughout the scholarship workflow.

---

### 💰 DBT Payment Tracking

Students can track the scholarship payment journey and monitor the status of their scholarship disbursement.

This improves transparency after the application has been approved.

---

### 🌐 Multilingual Assistance with JAGO

**JAGO** is an assistance layer designed to help students navigate scholarship information.

Supported languages include:

- English
- Hindi
- Gondi

JAGO helps make scholarship information more accessible to students from diverse linguistic backgrounds.

---

### 🔐 Privacy & Consent

VanDhan ScholarConnect follows a privacy-by-design approach.

Key principles include:

- Explicit user consent
- Data minimization
- Protected document handling
- Access control
- Audit logging
- Consent revocation
- Transparent data-access activity

> **Your data. Your consent. Your control.**

An officer-facing workflow allows authorized users to:

## 🛡️ Responsible Data Design

| Principle | Implementation |
|---|---|
| **Consent** | Explicit consent before accessing user data |
| **Data Minimization** | Collect only information required for the workflow |
| **Document Reuse** | Reduce repeated document submission |
| **Access Control** | Separate student and officer workflows |
| **Auditability** | Record data-access activity |
| **Transparency** | Provide application and payment status |
| **Revocability** | Allow users to revoke access |
| **Privacy** | Protect sensitive documents and identifiers |

The platform brings multiple scholarship journeys into a unified experience:

| Scholarship Scheme | Target Students |

| **Top Class Scholarship** | Students admitted to notified premier institutions |
